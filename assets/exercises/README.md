# Exercise assets

Use original or licensed local illustrations. No scraping or automatic image downloads.
Default mapping: `assets/exercises/<exercise.id>.svg`. Optional `image` overrides this
with a local `.svg`, `.png`, or `.webp` path in the same directory. Lowercase slugs only.
Missing images automatically use `fallback.svg`; no application edits are needed.
Illustrations are decorative: the card heading carries the exercise name.
